# Closing Cinematic — Overview

Pattern C. The act that returns the film's opening motif with a new meaning and ends on a single
call to action.

---

## THE SEQUENCE

```text
the product/company statement ("from the business's need to a product")
  → the operational material dissolves back into its raw modules
    → the camera pulls out of the workplace over a city turning to night
      → the modules rise into the night sky — the opening's star field, again
        → a controlled diagonal descent into the studio that makes the product
          → a closer, human-scale shot of the team
            → back up into a calm sky
              → the modules gather and assemble into a real, scannable code
                → the code card resolves; the call to action appears
                  → the page's contact section follows
```

## THE CENTRAL IDEA

**The closing is the opening played backwards in meaning, not in motion.**

| | Opening | Closing |
|---|---|---|
| The modules are | stars becoming a code | operational material becoming a code |
| The code is | a gateway — a way *in* | a destination — a way *to you* |
| The code is | stylised, flown through | real, scannable, presented flat |
| The camera | pushes in, crosses a threshold | pulls out, descends, settles |
| The world is | abstract night → concrete interior | concrete interior → abstract night |
| The reader is | being taken somewhere | being given something to do |

The reader does not need this explained. They recognise the shape — scattered squares gathering into
a code — and the recognition carries the meaning. That is the entire return on having kept one
visual protagonist for the whole film.

## WHY THE ENDING FEELS LIKE THE OPENING RETURNING

1. **Same objects.** The modules that assemble the final code are the same pool that was the opening
   star field, the code, and every interface element in between. Not similar objects — the same
   persistent identities.
2. **Same sub-feature, carried.** The finder square that was the opening's portal has been quietly
   present in the corner of the frame since the previous act ended; at the assembly it flies in and
   becomes the final code's top-left finder, cell for cell.
3. **Same sky.** The closing sky plate uses the opening sky's palette, ribbon and swirl recipe, with
   its big swirl centred on the final code exactly as the opening's was centred on the portal finder.
4. **Same grid.** The final code is version 2 — 25×25 — the same grid as the opening's stylised code.
5. **Inverted direction.** The opening's camera pushed in and crossed; the closing's pulls out,
   descends, and settles. The mirrored motion is what makes it read as an ending.

## NO PORTAL

The closing contains **no threshold crossing**. The film returns home by transformation and camera
travel inside one continuous space.

This is deliberate. A portal in the closing would compete with the opening's portal and devalue it.
The closing's transitions are:

- **dissolution** — a rendered panel breaks into the square dabs it is made of and floats away,
- **travel** — continuous multi-waypoint camera moves through one space,
- **a world-wide grade change** — evening becomes night by veiling, not by replacing,
- **gathering** — the modules assemble, which is the opening's own move.

## TIMING SHAPE

Proportions of the closing act (reference: 565vh, t 48.60 → 54.25):

| Beat | Share | Reference | Content |
|---|---|---|---|
| 1 · Return to the brand world | 35% | t 48.60 → 50.60 | dissolve, pull-back, night falls, modules rise |
| 2 · Company | 22% | t 50.60 → 51.85 | diagonal descent into the studio |
| 3 · Team | 16% | t 51.85 → 52.75 | closer, human scale |
| 4 · Final CTA / code | 27% | t 52.75 → 54.25 | rise to a calm sky, assembly, code, CTA |

Camera language gets calmer beat by beat: **pull-back → diagonal descent → small push → settle.**
That deceleration is the structural signal that the film is ending.

## COPY

Four blocks, one per beat, each on a settled frame:

1. who the company is,
2. what it does ("from the business's need to a product"),
3. how the team works,
4. the call to action.

Each enters after the camera has stopped and leaves before the next move. The fourth stays to the
end — and beyond, while the page's contact section scrolls over the still frame.

## THE ONE INTERACTIVE ELEMENT

The whole film is decorative and `pointer-events: none` except for one primary action in the final
frame. One button. One code. Both leading to the same place.

That restraint is what makes the call to action land: after 5,400vh of a film that could not be
clicked, the first clickable thing is unmissable.
